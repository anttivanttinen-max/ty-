VÄNÄ MotoLab – Contact RPM + Knock Sweep Tester v4

PÄÄTESTI
1. Kiinnitä AirPod/BT-kuuloke pinnapultin jatkomutteriin alumiinishimmillä tiukasti.
2. Käynnistä mikrofoni.
3. Käynnistä kamera ja suuntaa analogiseen kierroslukumittariin.
4. Kalibroi mittarin keskikohta, asteikon alku ja asteikon loppu.
5. Valitse mittauspaikaksi "Pinnapultin jatkomutteri + alumiinishimmi".
6. Paina ALOITA SWEEP ja kaasuttele rauhallisesti ylös ja alas useita kertoja.
7. Paina LOPETA SWEEP.
8. Vie JSON ja lataa myös viimeisin Sweep WAV.

TALLENNUS
- RPM-spektri: 20–1000 Hz
- Knock-spektri: 1–15 kHz, noin 50 ms seuranta
- Kamera-RPM aikaleimattuna sweepiin
- Mittarin viiveen automaattinen arvio
- Sweepin PCM-raakaääni WAV-muodossa (AudioContextin näytteenottotaajuus)
- Knock-event score ja tapahtumamäärä tutkimuskäyttöön

HUOM
Knock score EI ole vielä varma nakutustunnistin. Sen tarkoitus on kerätä normaali- ja poikkeamadatan erot myöhempää algoritmia varten.
Kamera toimii tässä vain testireferenssinä, ei normaalin MotoLab RPM Fusionin lähteenä.
